# Signed rectangle partitions · L-meta-4123

L-meta-4123 starts with a graph of girth at least seven whose nonisolated vertices have degree three, and deletes the edges incident to one such vertex. It asks for a partition into at most `t + 1` labeled rectangles whenever a circuit of size at most `t` computes the remaining graph's edge function. Rows are surviving edges, and columns are singletons or surviving edges. Every cell must belong to exactly one rectangle. Its label must be an endpoint of the row that is either in the column or adjacent to no vertex in the column. The general implication from circuit size remains open. [Graph and cell definitions](src/Cell.lean) · [Partition specification](src/GraphTransfer.lean)

The first child of the checked reduction proves that a signed partition of a suitable auxiliary function gives the required graph rectangles within its weighted slot bound. The remaining child asks for that certificate from a size-bounded circuit. The project checker printed children of 1,937 and 1,906 characters. The companion proves the first at its literal printed type and derives the original statement from the second alone. [Exact proved child](src/ClosedChild.lean) · [Remaining child](remaining.statement) · [Implication](src/FromRemaining.lean) · [Reduction](src/Reduction.lean)

**Removing negative labels.** Suppose a literal partition of the accepting and rejecting assignments has all its negative labels at one coordinate `v`. Write `P` for the number of positive rectangles and `Q` for the number of positive rectangles labeled outside `v`. The graph partition can be built with at most `P + Q` rectangles. For a rejecting column with `v = true`, raise that coordinate in the accepting row. The graph stays accepting and a negative label at `v` can no longer separate the two assignments. Splitting the affected positive rectangles preserves unique coverage. [Repair construction](src/LiftRow.lean) · [Slot count](src/SlotCount.lean) · [Graph bound](src/SignBudget.lean)

If all but a specified set of positive rectangles retain their row memberships under this change, only the exceptional ones need a second slot. There is also a dual repair that lowers the rejecting column. Either construction fits the original partition size when the number of duplicated positive rectangles is at most the number of discarded negative rectangles. A checked six-part partition for two disjoint edges illustrates the row repair. [Column repair](src/LowerColumn.lean) · [Same-size bound](src/GraphRepair.lean) · [Two-edge example](src/TwoEdges.lean)

**Several negative coordinates.** If no walk of length at most three joins two different negative coordinates, each graph column blocks at most one of them. The construction raises only that coordinate in the edge row. Its bound counts one slot per positive rectangle plus one for each marked coordinate where the row membership may change. It also works for a partition of an auxiliary function that accepts every input accepted by the graph and accepts additional inputs only when two distinct marked coordinates are true. [Short walks and blocked coordinates](src/ColumnMasks.lean) · [Graph-sample construction](src/SampleLift.lean)

On a matching of three disjoint edges, coordinates 0 and 2 lie in different components and both affect the edge function. A signed partition actually uses both negative labels on the same rejecting input. Each label is blocked by a singleton graph column, yet no graph column blocks both. For the same graph, adding the term `x₀ ∧ x₂` gives a function that differs on input `{0,2}` and agrees with the graph on every tested column and raised edge row. Its seven positive rectangles keep their row memberships under either raise, so the graph construction uses seven slots. On a two-edge matching, a different six-part example satisfies every graph test while missing a genuine accepting–rejecting pair. These examples illustrate the graph samples for matchings. [Separated negative coordinates](src/SeparatedExample.lean) · [Seven positive rectangles](src/ExtensionExample.lean) · [Sample-only partition](src/SampleOnly.lean)

The transfer from positive literal partitions to the edge-row and outer-neighborhood column samples follows PR #10101. The included girth lemmas show that each column's forbidden vertices form an independent set. On a graph from the assignment, the vertices used as labels of at least two rectangles form a vertex cover of the surviving graph. [PR #10101](https://github.com/open-goat/pequalnp-proofs/pull/10101) · [Positive transfer](src/GraphTransfer.lean) · [Girth lemmas](src/EdgeNegatives.lean) · [Repeated labels](src/Obstruction.lean)

## Reproduction

Use Python 3.9 or later, Git, and a checkout of `pequalnp-proofs` with `PEqualNP.Defs` and mathlib built. The publication base is `f0a159afb752cd39530ed7e78e7d427dbbd1d854`. The script also accepts the earlier baselines `19b9ebcdbad73b4e7dc900df1e5c49dc7034a8eb` and `2e67c7c8499e2e12d39c1f31c085c0e4e94b0391`. All three pin Lean `4.36.0` and mathlib `fc4f59e577feb1a4956671bc04ac18aaaf8cd842`. From this directory, choose a separate output directory and run

```sh
python build.py --upstream /path/to/pequalnp-proofs/lean --build-dir /tmp/rect-4123
```

The script compiles each module from source and then imports the selected theorems in a fresh Lean process. It checks their reported axioms against `propext`, `Classical.choice`, and `Quot.sound`. To check the exact proved child and its dependencies, append `--target ClosedChild:Rect4123.closed_extension`. Use `--lean /path/to/lean` for a release binary outside elan. [Build script](build.py)
